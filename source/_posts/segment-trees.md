每个算法笔记站都有一篇线段树教程，配四十行递归仪式。这里用一段话加几行代码讲完。

## 核心思想

把数组存成一棵完全二叉树，每个内部节点保存子节点的聚合值（求和、最小值，随便）。一次区间查询只碰 `O(log n)` 个节点；一次单点更新只修 `O(log n)` 个祖先。全部技巧就这些。

## 迭代写法

树放在长度为 `2n` 的扁平数组里，叶子在 `n .. 2n-1`，完全不需要递归：

```cpp
int n; vector<long long> t;
void build(const vector<long long>& a) {
    n = a.size();
    t.assign(2 * n, 0);
    for (int i = 0; i < n; i++) t[n + i] = a[i];
    for (int i = n - 1; i > 0; i--) t[i] = t[2*i] + t[2*i+1];
}
void update(int i, long long v) {
    for (t[i += n] = v; i > 1; i /= 2) t[i/2] = t[i] + t[i^1];
}
long long query(int l, int r) {        // [l, r)
    long long s = 0;
    for (l += n, r += n; l < r; l /= 2, r /= 2) {
        if (l & 1) s += t[l++];
        if (r & 1) s += t[--r];
    }
    return s;
}
```

`i^1` 就是 `i` 的兄弟节点。这一个异或，替掉了递归版本里所有左右子树的簿记。

## 循环边界为什么对

- 当 `l` 是奇数，它是右孩子——父节点覆盖了区间左侧之外的范围，所以直接取 `t[l]`，右移
- 当 `r` 是奇数，`r-1` 是左孩子——从另一侧做同样的论证
- 两者同时除以 2，窗口整体上移一层

> 递归写法用来理解这棵树。
> 迭代写法才是你在时间压力下敲的那个。

## 结论

线段树不是靠背下来的数据结构——它是一条不变量（"每个节点聚合子节点"）加一个寻址技巧（扁平数组，叶子偏移 `n`）。其余都是推论。
